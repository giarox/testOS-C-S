🚀 Quick Start

Option 1: Docker (Easiest)

# Pull and run the Docker container
docker pull unclecode/crawl4ai:latest
docker run -d -p 11235:11235 --shm-size=1g unclecode/crawl4ai:latest

# Test the scraper
curl -X POST http://localhost:11235/crawl \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://www.lidl.it/..."], "priority": 10}'

Option 2: Python (Local)

# Clone the repository
git clone https://github.com/giarox/testOS-C-S.git
cd testOS-C-S/crawl4ai-tests

# Activate virtual environment
source venv/bin/activate

# Run the scraper
python test_lidl_scraper.py
⚠️ Note: Local installation requires Chromium browser. See the setup guide for solutions.
