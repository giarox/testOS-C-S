## 🚀 How to Enable GitHub Pages

### From GitHub Web Interface:

1. Go to repository Settings
2. Navigate to "Pages" section (left sidebar)
3. Under "Source", select:
   - **Branch**: `claude/test-crawl4ai-scraper-15uh9`
   - **Folder**: `/docs`
4. Click "Save"
5. Wait a few minutes for deployment
6. Your site will be live at: `https://giarox.github.io/testOS-C-S/`

### Quick Setup Commands:

```bash
# Ensure you're on the correct branch
git checkout claude/test-crawl4ai-scraper-15uh9

# Commit and push the docs folder
git add docs/
git commit -m "Add GitHub Pages demo site"
git push origin claude/test-crawl4ai-scraper-15uh9
```
